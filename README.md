# 老虎机塔防 / 九宫防线（Slot Machine Tower Defense）

**当前版本：v1.2.0**

《九宫防线》是一款独立 H5 小游戏，将老虎机的随机/抽取机制与塔防的布防/波次玩法结合的轻量休闲游戏。

> ✅ **当前状态**：可玩原型 v1 已实现——按设计规格 v1.0.0 完整重写，9 波 3 Boss 完整闭环，核心流程已经过浏览器验证（含移动端触摸）。

## 性质
- **类型**：独立个人 H5 Web 游戏（竖屏移动优先）
- **产品名**：九宫防线；**项目代号**：老虎机塔防
- **不属于 AOEM**，不修改 `G:/Trunk`
- **技术栈**：单文件 HTML（`geminicode.html`，原生 HTML/CSS/JS，Pointer Events）
- **子任务 ID**：`slot-tower-defense`

## 本地运行

### 方式一：直接打开
双击 `geminicode.html` 即可在浏览器中运行。

### 方式二：启动本地静态服务（推荐）
```bash
# 在项目根目录（tasks/老虎机塔防/）执行
python -m http.server 8124
```
然后访问 `http://127.0.0.1:8124/geminicode.html`。

> ⚠️ 注意：直接访问 `http://127.0.0.1:8124/` 根路径会显示目录列表而非游戏，请带完整文件名。

## 玩法一句话
> 转老虎机获得建筑，摆进 3×3 九宫格抵挡 9 波敌潮；同类拖拽升星，配方自动合成高阶塔；击败第 9 波 Boss 即胜利。
