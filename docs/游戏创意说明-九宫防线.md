# 《九宫防线》T1 小游戏创意说明

## 一、一句话定位

《九宫防线》是一款肉鸽竖屏塔防小游戏，主打 **3~5 分钟一局、每次转盘都有翻盘可能、每次合成都能制造高光时刻** 的轻策略爽感。

## 二、10 秒卖点

- **第一眼能懂**：转老虎机出建筑，把建筑摆进 3x3 小棋盘里扛住敌潮。
- **第二层会惊喜**：同类建筑能升星，不同建筑一旦满足配方就会**自动合成**成更高阶炮台。
- **第三层会想炫耀**：一波神抽、神合成、Boss 反杀，天然适合做短分享和好友挑战。

## 三、为什么它适合做小游戏

### 3.1 碎片化适配

《九宫防线》的核心循环天然适合微信小游戏场景，因为它把整局体验压缩成非常清晰的短链路：

1. 开局布下基础建筑。
2. 敌人开始推进，玩家边守边抽。
3. 通过升星、换位、触发自动合成完成阵容跃迁。
4. 扛过一轮 Boss 或波次后结束结算。

这套循环的优点是：

- **上手快**：玩家不用读长说明，老虎机抽奖的逻辑具有普世性。
- **单局短**：一局目标非常明确，天然能收束到 3~5 分钟。
- **断点自然**：每一波敌潮、每次 Boss 前后、每次结算页，都能成为小游戏常见的停留与回流节点。
- **竖屏单手友好**：主战场、技能区、构筑区和老虎机按钮都能围绕竖屏布置，适合快速来一把。

### 3.2 社交裂变钩子（新增推演）

这款游戏最自然的分享点，不是“分享送奖励”，而是**分享自己的高光战局**：

- **神之一抽**：低血线时抽到关键建筑，瞬间翻盘。
- **神之一合**：配方条件凑齐后，建筑自动合成，高阶炮台直接扭转战场。
- **残局挑战**：Boss 还剩最后一截血，阵型已经快崩，玩家完成极限守住。

可以设计为：

- **炫耀型分享**：自动生成“本局最强合成 / 最高星建筑 / 翻盘瞬间”战报卡。


这样的裂变动机来自“我这局真的很秀”，而不是硬塞数值奖励，更符合小游戏生态。

## 四、游戏定位与核心玩法

### 4.1 目标用户

这款产品更适合以下两类人：

- **轻度塔防用户**：喜欢守线、看数值成长、享受阵容成型，但不想承受重度塔防的高学习成本。
- **休闲爽感用户**：喜欢抽卡、转盘、开盲盒、看爆点反馈，希望很快获得“中了 / 爆了 / 成了”的情绪奖励。

### 4.2 典型场景

- 通勤路上、排队间隙、午休前后的碎片时间来一局。
- 在广告素材、社交分享卡、好友挑战入口里被“这波抽奖/合成太爽了”吸引进来。
- 看完一局后不是被长线养成绑住，而是被“下一把能不能更胡”驱动再开一局。

### 4.3 核心玩法一句话

**玩家通过老虎机持续获得建筑，把建筑摆入 3x3 构筑区抵挡敌潮；同类建筑可升星，不同建筑满足配方后会自动合成为更高阶建筑，最终在短局内完成从苟活到反杀的阵容跃迁。**

### 4.4 核心循环

- **操作**：随机抽建筑、拖拽换位、观察战局
- **循环**：抽到建筑 → 放入九宫格 → 守住当前波次 → 升星 / 自动合成 → 阵容增强 → 迎战更强敌人。
- **爽感来源**：
  - 老虎机开出关键建筑的即时刺激。
  - 九宫格站位调整后火力刚好接上防线的“险过”感。
  - 满足配方后系统自动触发建筑合成带来的“顿悟式跃迁”。
  - 高阶塔出现后清屏、连锁、爆炸、落雷等强反馈造成的战场反转。

### 4.5 差异化卖点

- **老虎机不是外层包装，而是战局输入口**：每次抽取都直接影响防线。
- **3x3 九宫格让策略足够轻**：玩家不是管一整张大地图，而是在极小棋盘内做高密度决策。
- **自由拖拽换位降低试错成本**：阵容调整更像“摆机关”，不是沉重的卖塔重买。
- **子弹时间保证操作可控**：按住建筑、开老虎机、拖技能时，战场减速，降低手忙脚乱感。
- **配方自动合成制造爆点**：玩家关注的是“怎么凑出组合”，一旦条件满足，系统立刻把爽点打出来。

## 五、玩法系统速览

### 5.1 竖屏战斗结构

画面可以分成四块：

- **上半屏战场区**：怪物推进、塔自动攻击、Boss 进度显示。
- **左侧技能区**：放置一次性战术技能，作为解场工具。
- **下半屏构筑区**：常驻 3x3 建筑地格，是全部策略的核心操作区。
- **悬浮转盘按钮**：点击后进入老虎机弹层，抽取新的建筑结果。

### 5.2 建筑成长机制

- **直接落地**：随机抽取的建筑直接进入九宫格空位，不再经过手牌中转。建筑本身的连携效应让玩家单局内任意移动位置
- **同类升星**：同名建筑可通过重叠升级，从白色低星一路成长到高品质高星状态。
- **异类配方自动合成**：
  - 玩家要做的是凑齐指定配方建筑。
  - **一旦配方条件满足，系统立即自动执行建筑合成**，不需要玩家再手动拖拽确认。


### 5.3 动态权重卡池

老虎机不是纯平均随机，而是会随着战局推进动态调整权重：

- 前期更容易拿到基础建筑，保证能开局。
- 中后期逐步提高高阶建筑出现概率，避免纯卡手。
- Boss 临近时提高关键高稀有结果的保底感，让“翻盘局”更容易发生。

这保证了它虽然有随机性，但不会随机到让玩家完全无从发挥。

### 5.4 两套原型流派

#### A. 物理火药流

- 核心思路：用火箭、爆炸、攻速联动打出硬派清场。
- 代表建筑：短弓塔、投石机、火盆、铁匠铺、火药车。
- 高光瞬间：火箭命中路障后触发大范围爆炸，形成一波“轰过去”的战场快感。

#### B. 雷水共振流

- 核心思路：用潮湿、导电、连锁伤害做范围压制。
- 代表建筑：水炮塔、静电线圈、储能水槽、魔力棱镜、引雷避雷针。
- 高光瞬间：闪电连锁、八向溅射、范围落雷一起爆发，形成控制与清怪兼具的爽点。

### 5.5 战斗气质

这不是传统塔防那种“摆好就挂机”，也不是纯操作塔防。

它更像一种**即时轻策略**：

- 战斗是实时进行的。
- 建筑是自动输出的。
- 玩家主要负责“什么时候抽、抽到后放哪、要不要换位、这一波赌不赌合成”。

因此它的乐趣不是纯手速，而是**在有限空间里不断做正确的小判断**。

## 六、市场机会

### 6.1 竞品对标

它站在三个成熟用户认知的交叉区：

- **轻度塔防**：玩家天然理解“守住敌人、升级火力”。
- **合成成长**：玩家天然理解“凑两个 / 凑一套会变强”。
- **老虎机抽取**：玩家天然理解“开一下，看看能不能出货”。

也就是说，这个产品不是在教育一个全新品类，而是在把三种已经被市场验证过的快感重新组合。

### 6.2 真实差异化

真正的差异不在“我也有塔防，我也能抽卡”，而在下面这几点：

- 抽取结果不是局外养成，而是**即时战局变量**。
- 合成不是手动流程本身，而是**配方满足后自动爆发**。
- 棋盘极小，导致每一次放置和换位都更有重量。
- 爽点密度高，适合小游戏广告素材与短传播链路。

### 6.3 为什么是现在

当前小游戏市场里，纯超休闲越来越难靠单一点击动作留住用户，而过重的中度策略又容易把首局门槛拉高。《九宫防线》的机会在于：

- 用老虎机降低进入门槛；
- 用九宫格控制复杂度；
- 用自动合成和高反馈战场保证爽感；
- 用短局制保证它仍然是小游戏，而不是被做成一个过重的长期数值坑。

## 七、商业化路径

### 7.1 变现模型

建议采用 **IAA 为主、轻 IAP 为辅** 的混合模型。

- **IAA 主路径**：
  - Boss 前额外转一次老虎机；
  - 败局时观看激励视频获得一次续命或重抽；

- **轻 IAP 辅路径**：
  - 去广告或降低强插频次的轻订正权益；
  - 每局局外buff

### 7.2 社交传播设计

建议优先做两种可传播内容：

- **合成高光卡**：当玩家打出稀有自动合成时，生成一张可分享的“本局神合成”卡。
- **老虎机挑战**：爽玩老虎机，看最终能获得什么建筑
