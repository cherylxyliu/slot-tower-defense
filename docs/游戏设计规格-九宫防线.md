# 第一部分：设计概述

## 1. 定位与平台

- **产品形态**：竖屏移动网页游戏（H5），由单文件 HTML 原型演进而来；
- **交付目标**：完整打包供面试官查阅；离线可运行（双击打开或按 README 启动本地静态服务）；附一页玩法说明屏；
- **部署形态**：纯静态托管，无后端、无账号、无云存档、无 API 请求；
- **目标体验**：3~5 分钟一局的短周期构筑型肉鸽塔防——玩家在备战阶段做抽取与阵型决策，在战斗阶段验证决策，通过老虎机构筑投资形成局内成长差异。

### 1.1 需求背景

- **明确事实**：项目已有可运行单文件原型（`geminicode.html`），但存在 5 项 P0 缺陷（Boss 漏怪停机、触摸不可用、无胜负闭环、位置无战斗价值、平台未定）；用户经 25 轮裁决确认了完整重设计。
- **设计偏好**：用户明确要求"前置思考过程"而非"边打边抽"；老虎机自身可构筑；技能承担随机补偿与构筑取舍双重职责。
- **待验证假设**：前置构筑型分阶段循环能提供比即时肉鸽更强的决策满足感（见第五部分 5.1）。
- **设计推断**：双流派 + 老虎机三方向投资的组合空间足以支撑 3~5 分钟单局的重玩价值。

### 1.2 设计目的

- **要解决的问题**：原型的核心循环不完整（无胜负、位置无意义、移动端不可玩）；
- **希望提供的体验**：抽取时有期待、合成时有高光、换位时有策略、Boss 战有验证；
- **成功标准**：见第五部分 5.5 验收标准；
- **可能引入的新问题**：分阶段循环可能让战斗阶段观感偏被动（用技能与合成演出缓解）。

## 2. 单局结构与胜负规则

### 2.1 波次结构

全局共 **9 波**，分 3 个阶段，每阶段 2 个普通波 + 1 个 Boss 波：

| 阶段 | 波次 | Boss |
|---|---|---|
| 一 | 第 1、2、3 波 | 第 3 波：装甲巨人 |
| 二 | 第 4、5、6 波 | 第 6 波：召唤领主 |
| 三 | 第 7、8、9 波 | 第 9 波：狂暴魔王 |

### 2.2 波次结束条件（数量制）

- 每波有固定敌人数量：第 1 波 8 只，逐波 +1，第 9 波 16 只（不含 Boss 与召唤物）；
- 波内所有敌人被击杀或漏过后，波次结束进入结算；
- 无时间上限，无波内刷新上限。

### 2.3 胜负规则

| 事件 | 结果 |
|---|---|
| 击败第 9 波 Boss（狂暴魔王） | **胜利**，进入结算屏 |
| 基地生命归零 | **失败**，进入结算屏 |
| 普通怪漏过（到达战场底部） | 基地生命 -1 |
| Boss 漏过 | 基地生命 -5 |

- 基地初始生命：**10 点**；
- Boss 漏过后（生命未归零）进入下一波，不重打该 Boss；
- 第 9 波 Boss 漏过且生命未归零：本局失败（最终 Boss 漏过无后续波次可翻盘，视为防线崩溃）。

> 边界：若第 9 波 Boss 漏过导致生命恰好归零，按失败处理（同一事件取更严重结果）。

## 3. 核心循环

```text
备战阶段（不限时：转老虎机 / 商店购买 / 换阵 / 同类升星 / 老虎机投资*）
→ 玩家点击「开始战斗」
→ 合成阶段（锁定九宫格 → 自动执行异类配方 → 播放合成动画）
→ 战斗阶段（建筑自动作战，玩家只释放战术技能）
→ 波次结算（铜钱 + 金币到账，无漏怪有额外奖励）
→ 下一波备战
```

- *老虎机投资在第 2、4、6、8 波结算后触发（见第 6 章）；
- 战斗期间**禁止**抽取、换位、升星和合成；唯一玩家操作是释放战术技能；
- 第 1 波备战无商店（初始金币为 0）；第 2~9 波备战均开放商店；
- 波次 9 结束（胜利或失败）不再进入备战，直接进入结算屏。

# 第二部分：功能规则

## 4. 资源系统

### 4.1 双货币

| | 铜钱 💰 | 金币 🪙 |
|---|---|---|
| 唯一用途 | 转动老虎机 | 商店购买技能；刷新商店技能列表；刷新老虎机投资选项 |
| 定位 | 软货币（大量、持续投放） | 硬货币（稀缺）+ **抽奖保底安全网** |
| 初始值 | 150 | 0 |
| 每波保底收入 | 30（随波递增） | 普通波 1 / 精英 8 / Boss 8 |
| 击杀普通怪 | +3 | — |
| 击杀 Boss | +70 | +5 |
| 跨波继承 | ✅ 剩余保留 | ✅ 剩余保留 |

- **金币的"保底"定位**：普通波稳定投放 1 金，让"运气差、抽奖不顺"的玩家也能攒金币去商店直接购买道具，降低对抽奖结果的乘法依赖；精英/Boss 节点才是金币大头，维持稀缺感。
- 未中奖**不返还**铜钱（老虎机聚财流构筑可提供返还能力，见附录 D）；
- 金币不可兑换铜钱，铜钱不可兑换金币。

### 4.2 抽取消耗（阶梯递增，每波重置）

| 备战阶段内第几次抽取 | 消耗铜钱 |
|---|---|
| 第 1 次 | 6 |
| 第 2 次 | 12 |
| 第 3 次 | 22 |
| 第 4 次 | 45 |
| 第 5 次及以后 | 90（自然上限，实际不鼓励） |

- 每波进入备战时，抽取消耗重置为第 1 次（6 铜）；
- **玩家体感标尺 = 本波收入能抽几次**：开局 150 底仓只够第 1 波启动，不计入后续波次。前 3 次总和 40 ≤ 第 1 波收入（约 43），保证前期普通波也能抽满 3 次凑初始 build；后段 45/90 保留"攒一波"压力，使中后期普通波稳定抽 3~4 次、Boss 波可抽 6+ 次形成丰收情绪高点。
- 递增设计使单波抽取自然收敛在 3~4 次。

### 4.3 商店消费说明

- 商店候选含 **1 个常驻血包 🩹 + 若干技能**，玩家可**直接挑选购买**，**无需刷新**；
- **血包**：3 金/个，购买即恢复 1 点基地血量（即时消耗品，不占技能携带栏）；**满血（10/10）时禁止购买**，避免浪费。血包让金币有刚需出口——后期怪物变强后，回血成为生存刚需。
- "刷新"（重 roll 候选）是**可选消费**，阶梯计费（见 §4.4），刷不起不影响核心循环——前期金币稀缺时完全可跳过刷新、只买心仪件；
- 投资三选一免费必选，仅"刷新候选"收费。

### 4.4 怪物强度曲线（难度加压）

- 怪物生命值 = 基础 hp × 节点 `hpMult`；`hpMult` 随波次递增（1.00 → 3.00），**前期平缓、后期陡增**；
- 后期节点（id≥11）的 `hpMult` 已上调（如终局真·Boss id18 由 2.55 → 3.00），使满 build 也需认真对待后期怪潮，从而消化金币（血包/技能）；
- 设计意图：用难度换取金币消耗深度——"我太强了没有消费需求"的问题，靠拉高后期怪物强度根治。

### 4.5 经济闭环验算（自拟，待审）

- 全局铜钱收入估算：普通波 6 × ~81 + Boss 波 3 × ~151 ≈ **939**；
- 全局抽取次数估算：初始底仓抽 3~4 次 + 普通波 6 × 3 次 + Boss 波 3 × 6+ 次 ≈ **40+ 次**（前段成本下调后单波可抽次数略增）；
- 全局金币收入：普通波保底 12（12 个普通波 ×1）+ 精英/Boss 节点约 68 → 合计约 **80 金**（全漏怪下限略低，视运气浮动）；
- 金币消费：技能直接购买 3~5 金（不刷新亦可）+ 可选刷新 → 每局约 8~15 次消费机会；前期金币稀缺时以"直接买"为主、刷新为补充。

## 5. 老虎机系统

### 5.1 滚轴与中奖线

- 3×3 滚轴，每列除可见 3 格外含隐藏后续图标（每列独立隐藏序列，抽取时随机生成整列）；
- 8 条中奖线：3 横 + 3 竖 + 2 斜；
- **多线独立结算，不去重**：同一建筑同时形成 2 条线，获得 2 个该建筑。

### 5.2 抽取流程（六步）

```text
① 能力预检（目标概率增益 / 免费抽取 / 铜钱是否足够）
② 消耗铜钱，三列转动，展示 9 个图标
③ 首次结算：检查全部 8 线，每条中奖线独立发放建筑
   → 建筑自动进入九宫格空位；九宫格满则进入备战暂存区
④ 后处理能力展示（当前可用的列隐藏预览 / 剩余下移次数 / 中心交换等）
⑤ 玩家调整：选择一列下移 1 格 /（拥有能力时）中心格交换
   → 每次有效调整后，重新检查受影响的中奖线，新增线立即结算
⑥ 调整结束，返回备战界面
```

### 5.3 通用列下移（所有玩家默认拥有）

- 每波备战阶段内共 **1 次**（获得连线爆发流能力可提升为 2 次）；
- 选择一列向下移动 1 格：隐藏图标从顶部进入，原底部图标离开可见区域；
- 下移后重新检查**受影响的**中奖线，新形成的线立即结算；
- **滚轴真实推进即有效**：下移前后同列显示相同建筑（如三个短弓仍是三个短弓），该列仍再次中奖并再次发奖；
- 次数用尽或玩家主动放弃后，本波内不可再用；未使用次数波次结束时不累计。

### 5.4 中心格交换（定向流构筑能力，非通用）

- 触发条件：拥有该能力 **且** 本次抽取未中奖（无任何中奖线）；
- 将中心格（第 5 格）与外围 8 格中任意一格交换位置；
- 交换后重新检查全部中奖线，新增线立即结算；
- 两格图标相同时不允许执行（画面无变化，防止无效刷奖）；
- 每次抽取最多执行 1 次。

### 5.5 保底规则

- 连续 2 次抽取未中奖（含调整后仍无新增线），下一次抽取**必定**获得 1 个建筑；
- 保底建筑 = 当前倾斜流派（见 5.6）的 Tier 1 基础塔中随机一个；
- 保底建筑发放不走滚轴，直接进入九宫格或暂存区；
- 触发后连续未中奖计数归零。

### 5.6 动态权重（流派倾斜）

- 抽取池含两套流派全部 10 种基础建筑（Tier 1 + Tier 2，不含合成产物）；
- 系统统计九宫格 + 暂存区的流派组件数：
  - 某流派 ≥2 个组件：该流派符号权重 ×1.5，另一流派 ×0.7；
  - 某流派 ≥5 个组件：×1.8 / ×0.5；
  - 两流派均 <2 或均达标（混合构筑）：不倾斜；
- **概率变化必须透明展示**：老虎机界面常显当前各建筑实际出现概率；
- 基础权重与倾斜后产出率验算见附录 E。

### 5.7 抽取界面信息

- 当前铜钱 / 金币余额；
- 本次抽取消耗（含阶梯位置提示，如"本波第 3 次抽取，消耗 40"）；
- 当前流派倾向与概率面板；
- 剩余列下移次数图标；
- 可完成配方提示（高亮当前集齐材料的配方）。

## 6. 老虎机构筑投资

### 6.1 投资节奏

- 第 2、4、6、8 波结算后各触发 1 次，全局共 **4 次**；
- 每次从能力池随机展示 **3 个能力（三选一）**，免费选择 1 个；
- 可支付 **2 金币** 刷新整组选项（原 A/B/C 替换为新 D/E/F），刷新次数不限（受金币约束）；
- **当场必须选择，不可保留**到以后；
- 界面常显"距下次老虎机投资还有 X 波"。

### 6.2 三方向

| 方向 | 核心体验 | 能力示例 |
|---|---|---|
| 聚财流 | 同样铜钱多转几次 | 未中奖返还、累计免费抽取、中奖返扣 |
| 定向流 | 把结果修正到想要的方向 | 目标建筑概率 +5%、未中奖中心交换、图标锁定 |
| 连线爆发流 | 连续中奖时单抽产出更多 | 列下移 +1、连击额外 +1、中奖后概率 +5%、预览隐藏图标 |

完整能力池（12 条，含数值与稀有度）见**附录 D**。

### 6.3 能力获取规则

- 已获得的能力不再出现在后续三选一选项中（无叠加）；
- 单次三选一不出现重复条目；
- 选项按稀有度加权随机：常见 50% / 稀有 35% / 史诗 15%。

### 7.2 邻接规则

- **邻接 = 上下左右直接相邻，不含斜角**；
- 九宫格格子本身无属性差异；
- 玩家在备战阶段自由换位调整增益覆盖；
- 邻接增益与异类配方无关（配方是全棋盘匹配）。

### 7.3 射击规则

- 每个攻击建筑从九宫格对应列的战场底部位置发射（左列 → 左半区、中列 → 中路、右列 → 右半区）；
- **目标选择**：射程内最靠近战场底部（威胁最大）的敌人；
- **射程**：以战场高度的百分比表示，从发射位置起算的圆形范围；
- 单体目标数 +1 效果（魔力棱镜）：同时攻击 2 个符合目标选择规则的敌人，各造成全额伤害；仅对单体攻击建筑生效，范围/连锁攻击不受益。

### 7.4 同类升星

- 任意两个同名建筑拖拽重叠合并（九宫格内、九宫格与暂存区之间、暂存区内均可）；
- **结果星级 = 两者星级之和 + 1**，上限 5 星；
- **结果超过 5 星时不允许合并**（如 3 星 + 2 星）；
- 5 星建筑不能再作为升星材料；
- 界面拖拽时预览合并结果，超上限时提示"将超出星级上限"；

**升星成长（分段）**：

| 星级 | 增幅（相对 0 星） |
|---|---|
| 1 星 | +50% |
| 2 星 | +100% |
| 3 星 | +180% |
| 4 星 | +260% |
| 5 星 | +340%（即 0 星数值 × 4.4） |

- 攻击建筑：伤害按上表增长；
- 辅助建筑：增益幅度按上表增长（如火盆 5 星 → 相邻短弓伤害 ×8.8）；
- 触发器：触发伤害按上表增长。

### 7.5 异类配方合成

- 全局仅 2 条配方：短弓塔 + 火盆 = 重型火箭塔；水炮塔 + 静电线圈 = 雷暴降临塔；
- **全棋盘匹配**：材料在九宫格或暂存区任何位置均可参与，不要求相邻；
- 合成时机：波前合成阶段自动扫描（见 7.6）；
- **合成产物固定 0 星**；
- 消耗升星过的材料时，按材料星级返还铜钱补偿（见附录 C），补偿在合成时自动到账。

### 7.6 波前合成阶段流程

```text
① 玩家点击「开始战斗」→ 九宫格与暂存区锁定
② 系统扫描全部可完成配方（材料来源：暂存区 + 九宫格）
③ 展示合成预览：全部可完成配方 + 系统推荐组合
   → 材料来源标注（暂存区 / 九宫格）
   → 存在材料冲突的配方用文字标签「冲突」标出
④ 玩家选择本波要执行的配方组合（默认勾选推荐方案）
   → 若动用九宫格材料，逐项预览"该合成将消耗上阵的 X 星 Y"
   → 玩家确认
⑤ 系统自动依次执行合成，逐个播放动画（1.5~2 秒/个）
   → 材料消耗顺序：优先暂存区 → 不足时用九宫格
   → 产物优先进入材料腾出的九宫格，否则进入暂存区
⑥ 全部合成完成，进入战斗
```

- 动画可点击跳过当前单个，或点「跳过全部」；
- 合成阶段不限时；
- 无可完成配方时，显示"本波无可用配方"，一键跳过。

## 8. 备战暂存区

- 九宫格满时，中奖建筑自动进入暂存区；

# 第五部分：策划自问自答

## 5.1 希望提供的体验

**问**：玩家通过本设计应获得什么感受？哪个行为能证明？删除什么会损失核心？

**答**：核心感受是"我的构筑决策决定了战局"。证明行为：玩家在备战阶段主动换位调整邻接关系、在配方冲突时做出取舍、在金币有限时选择买技能还是攒刷新。若删除波前合成阶段或邻接系统，九宫格退化为纯摆放区，核心卖点即丧失。

## 5.2 解决问题

**问**：原型的根本问题是什么？本设计是否治根？

**答**：原型根本问题是"位置无意义 + 无胜负闭环 + 移动不可玩"，三者共同导致构筑无目的。本设计用邻接增益（位置有意义）、9 波 3 Boss 数量制（闭环）、Pointer Events（可玩）分别治根；合成演出与透明概率解决"自动等于黑箱"的次生问题。

## 5.3 规则自检

**问**：是否存在唯一最优解或无意义步骤？

**答**：已知风险点——① 聚财流在 4 次投资中若全选，铜钱滚存可能使后期每波抽 5 次+（阶梯 160 消耗自然抑制，观测指标见附录 F）；② 铁匠铺攻速 +30% 若作用于所有相邻攻击建筑，摆中心位覆盖 4 格可能是唯一最优（用棱镜/火盆的差异化覆盖制造竞争）；③ 暂存区无限可能导致囤积无压力（观测实际利用率，必要时加消耗出口）。以上均列为待观测项，不在首版加规则。

## 5.4 体验自检

**问**：新概念是否过多？玩家能否预测结果？

**答**：新概念 7 个（双货币、滚轴、列下移、中心交换、邻接、配方、投资），通过玩法说明屏 + 首波引导性简化（第 1 波无商店无投资，仅抽取与开战）控制节奏。预测性：概率面板、配方预览、合并预览、消耗预览均已设计为透明展示。

## 5.5 开发与验证自检

**问**：从哪个模块开始实现？禁止开发自行解释什么？验证分层？

**答**：
- 实现顺序：状态机（波次/阶段/胜负）→ 老虎机（滚轴/结算/下移）→ 建筑（射击/邻接/升星/合成）→ 敌人 Boss → 技能商店 → 投资系统 → 界面打磨；
- **禁止开发自行解释**：合成产物星级规则（固定 0 星）、多线不去重、列下移重复中奖条件（滚轴真实推进）、超上限禁止合并——此四条最易被"直觉"改错；
- 自动测试验证：状态机流转、滚轴概率、经济数值；真实运行验证：移动触摸、合成动画、性能；数据观察验证：附录 F 全部指标；用户验收验证：核心体验是否成立。
